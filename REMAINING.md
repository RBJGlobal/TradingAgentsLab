I ran an aggressive regression sweep (architect + 4 code-reviewers across engine, renderer, Electron). **3 confirmed-breaking bugs are already fixed + tested** (see WORKLOG / Handover). ### 2a. Security hardening (recommend doing first)
- **`main.ts:94-96` — `openExternal` has no protocol allowlist.** All `window.open` URLs go to the OS; `file:`/`javascript:` are structurally undefended (narrow in prod, but should be gated to `http(s):`). Clear, safe fix.

### 2b. Renderer UX bugs (confirmed; need a component-test harness first)
- **`Settings.tsx:719`** — Local-LLM manual-entry form doesn't close on a successful save (stale-closure on `saveError` after `await`).
- **`DebateStream.tsx:251-256`** — elapsed clock doesn't start on a 2nd analysis in the same app session (`endedAtRef` not reset on re-run).
- **`Analyze.tsx:635-649`** — theoretical stale ticker/date on Cmd+Enter (very low probability; lint-suppress hides it).
- *Why deferred:* there's no React component-test harness yet, so I can't guard these fixes against regression. Recommend I add a small React Testing Library harness, then fix all three with tests.

### 2c. Dead-code cleanup batch (all confirmed zero-reference; verify each grep before removal)
- `engine-client.ts` — `analyze()` + `AnalyzeResponse` (dead HTTP path; all analysis uses the WS stream)
- `oauth-openai.ts:346` — `getCredentials()` (zero refs)
- `secrets.ts:52` — `EncryptionUnavailableError` export (thrown internally only → drop `export`)
- *Verify-first (may be test-referenced):* `OPENAI_OAUTH_SECRET_KEY`, `menu.ts:23 buildMenu`, `llm_providers.py:283 default_model_for` (used by tests — keep), `cost_guard.py:683 estimate_cost` re-export.

### 2d. Minor robustness (low impact; fix opportunistically)
- `engine-runner.ts:165` — handshake parse error can embed a partial bearer token if JSON splits across pipe buffers (accumulate to newline, or redact).
- `window-state.ts:34-50` — no upper cap on restored window size vs screen (corrupt state → giant window).
- `telegram_bot.py` `stop()` — in-flight handler tasks aren't cancelled; one resuming after `_client=None` hits an assert (only on restart; loses final reply).
- `webhooks.py:312-314` — unreachable `except asyncio.TimeoutError` (httpx raises its own type; harmless dead branch).
- `__main__.py:27-33` — TOCTOU on port reservation (harmless in prod single-process).
- **Alpaca incomplete-bar mirror:** the Alpaca path has the same class of issue I fixed for yfinance tonight — a null/forming last bar makes `last_close` fall to `0.0` (a fake price). Recommend mirroring the yfinance "drop incomplete bars" guard. Untestable here without your Alpaca keys; needs a live check.

### 2e. Contract / doc drift (zero runtime risk)
